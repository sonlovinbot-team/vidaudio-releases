# VidAudio · Bản phát hành

Nơi tải VidAudio cho macOS (Apple Silicon, macOS 14 trở lên).

- **Tải về:** xem mục [Releases](https://github.com/sonlovinbot-team/vidaudio-releases/releases/latest).
- **`news.json`:** app VidAudio đọc file này (qua GitHub Pages) để biết có bản mới. App chỉ gửi một yêu cầu GET thường, không gửi ID hay dữ liệu người dùng.

Repo này không chứa mã nguồn.
